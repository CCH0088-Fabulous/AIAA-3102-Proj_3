## Introduction

This repository implements a three-stage video object removal workflow.

- Part 1 is a classical baseline built around YOLOv8-Seg, sparse optical flow, mask cleanup, temporal background borrowing, and OpenCV inpainting.
- Part 2 is a higher-quality pipeline built around SAM2 mask propagation and ProPainter video inpainting.
- Part 3 refines Part 2 masks with SAM3 and supports generative fallback for persistent occlusions before temporal inpainting.

The previous long-form README has been preserved as `README_Outdated.md`.

## Part 1

### Model

Part 1 combines:

- YOLOv8-Seg for candidate instance masks
- sparse Lucas-Kanade optical flow for dynamic/static filtering
- temporal propagation for background recovery
- OpenCV inpainting as fallback filling

### Structure

- Entrypoint: `src/part1_baseline/pipeline_part1.py`
- Detection: `src/part1_baseline/mask_extraction_yolo.py`
- Motion filtering: `src/part1_baseline/dynamic_judgment.py`
- Inpainting: `src/part1_baseline/inpaint_traditional.py`
- Shared utilities: `src/common/`

### Configuration

- Shared dataset, naming, and output settings: `configs/common.yaml`
- Part 1 phase config: `configs/part1_baseline.yaml`
- Default target classes: `person`, `bicycle`
- Key tunable blocks: `dynamic_filter`, `postprocess`, `inpainting`, `visualization`

### Outputs

- Masks: `results/masks/part1/{sequence}/`
- Video: `results/videos/part1/{sequence}_part1.mp4`
- Visualizations: `results/visualizations/part1/{sequence}/`
- Metrics: `results/metrics/part1/{sequence}/`

### Run Commands

Run the default Part 1 sequence:

```bash
python src/part1_baseline/pipeline_part1.py \
  --common-config configs/common.yaml \
  --phase-config configs/part1_baseline.yaml
```

Run a specific sequence:

```bash
python src/part1_baseline/pipeline_part1.py \
  --sequence parkour \
  --common-config configs/common.yaml \
  --phase-config configs/part1_baseline.yaml
```

Quick smoke test:

  --phase-config configs/part1_baseline.yaml

```# Video Object Removal and Inpainting

This repository implements a staged video object removal project. The currently implemented pipelines cover Part 1 as a classical baseline built around YOLOv8-Seg, sparse optical flow, temporal background propagation, and traditional image inpainting, plus Part 2 as a higher-quality SOTA pipeline built around SAM2 mask propagation and ProPainter video inpainting.

Part 1 is no longer just a mask extraction demo. It now runs a full baseline pipeline:

1. Detect candidate dynamic classes with YOLOv8-Seg.
2. Use Lucas-Kanade sparse optical flow to decide whether each detected instance is actually moving.
3. Postprocess masks with dilation, hole filling, connected-component cleanup, and short temporal smoothing.
4. Restore the video by borrowing clean background pixels from nearby frames first.
5. Fill any remaining holes with `cv2.inpaint` using Telea or Navier-Stokes.
6. Export masks, restored video, visualization artifacts, and evaluation metrics.

## Figures

`src/common/figure_scripts/` contains the figure-generation entrypoints and shared plotting modules used to convert metric CSVs into publication-style PNG figures.

### Overview

- `generate_metric_figures.py` generates the main figure suite under `results/visualizations/figures/`
- `generate_metric_figures_davis.py` generates the DAVIS-only figure suite for `parkour` and `dance-twirl` under `results/visualizations/figures/davis/`
- `generate_wild_comparison.py` generates the Wild Video qualitative comparison figure
- `metric_figure_data.py`, `metric_figure_plots.py`, `metric_figure_output.py`, and `metric_figure_constants.py` provide the shared data loading, plotting, output, and naming logic

### Wrapper Script

Run all three figure-generation commands in sequence with:

```bash
bash run_all_figure.sh
```

### Prerequisites

Before generating figures, make sure metric CSVs already exist under `results/metrics/{part1,part2,part3}/{sequence}/`.

Typical workflow:

```bash
python scripts/evaluate_metrics.py --phase-config configs/part1_baseline.yaml --sequence parkour
python scripts/evaluate_metrics.py --phase-config configs/part2_sota.yaml --sequence parkour
python scripts/evaluate_metrics.py --phase-config configs/part3_exploration.yaml --sequence parkour
```

Repeat that for every sequence you want included in the plots.

### Main Figure Suite

Generate the overall figure set:

```bash
python src/common/figure_scripts/generate_metric_figures.py \
  --metrics-root results/metrics \
  --output-dir results/visualizations/figures
```

This writes summary CSVs, a generated README manifest, distribution plots, frame-wise trend plots, paired-delta figures, heatmaps, and summary tables into `results/visualizations/figures/`.

### DAVIS Figure Suite

Generate the DAVIS-only figure set:

```bash
python src/common/figure_scripts/generate_metric_figures_davis.py \
  --metrics-root results/metrics \
  --output-dir results/visualizations/figures/davis
```

This writes the same style of metric visualizations, but restricted to `parkour` and `dance-twirl`.

### Wild Video Comparison

Generate the Wild Video qualitative comparison figure:

```bash
python src/common/figure_scripts/generate_wild_comparison.py
```

### Notes

- All figure scripts write PNG outputs.
- The plotting style is centralized in `metric_figure_plots.py`.
- The scripts resolve output paths from the repository root, so running them from the project root is the safest option.
